# Week 3: Password Cracking Labs

Hands-on labs focused on extracting password hashes and recovering credentials from an encrypted PDF file.

## Completed Modules

### Project Module 1: Password Cracking with John the Ripper (JTR)
* **Tools Used:** John the Ripper (CLI) and Johnny (GUI)
* **Summary:** Extracted the password hash from the protected PDF file and cracked the password using both the command-line interface and the graphical front-end.

### Project Module 2: Password Cracking with Networkwalks Tools
* **Tools Used:** Networkwalks Hash Calculator and Networkwalks Password Cracker
* **Summary:** Extracted the file's stored hash using the browser-based Hash Calculator and recovered the plaintext password through the Password Cracker

## Important discoveries 
* Protected files store passwords as cryptographic hashes rather than plain text
* Weak or short passwords can be cracked rapidly across both local utilities and browser-based tools, reinforcing the need for strong, complex passwords.
