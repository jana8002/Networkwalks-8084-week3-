## Important discoveries 
* Protected files store passwords as cryptographic hashes rather than plain text[span_8](start_span)[span_8](end_span).
* Weak or short passwords can be cracked rapidly across both local utilities and browser-based tools, reinforcing the need for strong, complex passwords[span_9](start_span)[span_9](end_span)[span_10](start_span)[span_10](end_span).
